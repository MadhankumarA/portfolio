What I actually do all day

I'm a backend and cloud engineer working mostly below the application layer — the systems that keep other services running. That means Go and Python backend services, OpenStack Octavia/Nova control-plane and data-plane work, and Kubernetes-based deployments.

Day to day, that looks like debugging why a load balancer's database state drifted from its actual infrastructure, building the API that returns amphora health, or writing the internal dashboard someone on my team needed at 11pm during an incident.

I like understanding systems end-to-end — from a request landing on a listener, through certificate validation, to which backend node ends up handling it. Lately I've also been building small AI-agent side projects on top of local LLMs, mostly to see how the same reliability thinking applies outside infra.

Featured work

01
Intelligent System Design Interview Simulator
problem
System design interview practice is hard to get without a human on the other end — and local LLMs are a cheap, private way to fill that gap, except their raw output is inconsistent free-form text, not something a UI can score.
approach
Built a FastAPI service around locally hosted Llama models via Ollama, streaming interview dialogue in real time. Added a two-stage evaluation pipeline: stage one lets the model reason freely about the candidate's answer, stage two re-prompts it to convert that reasoning into structured, reliably-parseable feedback — with retry/repair logic for the malformed JSON local models often produce.
outcome
A working end-to-end simulator: question generation, context-aware follow-ups, and structured scoring — running entirely on local infrastructure with no external API dependency.
